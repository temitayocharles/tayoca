02 · Clear boundaries

Free should mean free.

If you are selected, the promised core build does not suddenly become conditional on purchasing something else.

Discussed separately only when useful

  • Domain or long-term hosting costs
  • Secure owner CMS or /admin capability
  • Ongoing maintenance and security updates
  • Managed local SEO and reporting
  • E-commerce or custom application features
  • Booking, payment, CRM and automation systems

You can decline every optional add-on and still receive the agreed free core build.

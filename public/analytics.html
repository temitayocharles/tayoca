How to read this dashboard

Live website activity comes from Tayoca's first-party analytics collector. Google Search metrics come from a verified Search Console API snapshot and include the data-through date because finalized Search Console data lags current traffic. Revenue, proposals and pipeline values remain governed by the Stage 11 commercial ledgers and verified revenue evidence. Missing or stale Google data must be presented as unavailable or stale, not silently fabricated as zero.

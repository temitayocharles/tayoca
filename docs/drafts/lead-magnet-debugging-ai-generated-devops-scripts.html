Failure is only half the problem

Generated automation can be wrong even when it runs.

A script can succeed syntactically and still delete too broadly, retry too aggressively, fan out without bounds, wait forever, leak secrets, touch unexpected state, or report success while doing the wrong amount of work.

Failure

Catch the obvious break

Missing timeouts, broken exit-code handling, pagination errors, failed backups, bad pipeline semantics and rollout failures.

Overreach

Catch the script doing too much

Unsafe deletion scope, unbounded concurrency, uncontrolled retries, indefinite waits, secret exposure and assumptions that are only safe on one machine.

Evidence

Defend the fix

Use exit codes, stderr, files, timings, events and tests to prove what failed, why the fix works and what risk remains.

Failure is only half the problem.

Generated automation can be dangerous even when it does not crash. It can delete too broadly, wait too long, retry too aggressively, fan out without bounds, touch unexpected state, leak secrets, or report success while doing the wrong amount of work.

The practice pack trains you to recognize both categories: failure and overreach.

How each lab works

  1. Read the broken script.
  2. Predict the failure or overreach before running it.
  3. Run it against safe local fixtures and collect evidence.
  4. Make the smallest safe fix.
  5. Explain why the fix works and what risk remains.
